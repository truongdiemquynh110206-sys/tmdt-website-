# Bát Việt — Website thương mại điện tử gốm Bát Tràng

Website mô phỏng phục vụ bài tập thương mại điện tử.

## Chạy trên GitHub Pages
1. Tạo repository trên GitHub.
2. Upload `index.html`, `style.css`, `script.js`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch → main → / (root) → Save**.
5. Mở đường link GitHub Pages được cung cấp.

## Chức năng
- Responsive desktop/mobile
- Danh mục và lọc sản phẩm
- Giỏ hàng bằng JavaScript
- Tăng/giảm số lượng
- Lưu giỏ hàng bằng LocalStorage
- Form đăng ký email
- Điều hướng theo section
