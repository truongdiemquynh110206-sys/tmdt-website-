# BÁT VIỆT — Website thương mại điện tử gốm Bát Tràng

Website mô phỏng phục vụ bài tập thương mại điện tử.

## File

- `index.html` — giao diện website
- `style.css` — thiết kế giao diện
- `script.js` — sản phẩm, lọc và giỏ hàng

## Đưa lên GitHub Pages

1. Tạo Repository trên GitHub.
2. Chọn **Public**.
3. Upload 3 file trên vào thư mục gốc của Repository.
4. Nhấn **Commit changes**.
5. Vào **Settings → Pages**.
6. Chọn **Deploy from a branch**.
7. Chọn **main** và **/ (root)**.
8. Nhấn Save nếu GitHub yêu cầu.
9. Chờ GitHub Pages build website.

## Chức năng

- Trang chủ
- Danh mục sản phẩm
- Lọc sản phẩm
- 8 sản phẩm mẫu
- Hình ảnh gốm
- Giỏ hàng
- Tăng / giảm số lượng
- Xóa sản phẩm
- Lưu giỏ hàng bằng LocalStorage
- Form đăng ký email
- Responsive trên điện thoại
- GitHub Pages compatible
